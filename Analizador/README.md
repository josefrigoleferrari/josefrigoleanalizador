## Introducción

Este es un Analizador de expresiones aritméticas construido con ANTLR4, lenguaje Java en VS Code

## Requisitos
Tener instalado VS Code, Node .js, Java JDK

## Instalación
En alguna terminal, puede ser la de VS Code o Microsoft Powershell pegar el siguiente código para poder clonar el proyecto

git clone https://github.com/josefrigoleferrari/josefrigoleanalizador.git

## Comprobación
Para comprobar que el programa funcione, una vez abierto en VS Code escribir en la terminal: npm start ; y deberaía aparecer que el programa se ejecuta correctamente.
Y para comprobar si los input.txt son válidos o no para la gramática, seleccione el archivo y presione f5 y le aparecerá en la debugg concole si es válido y que valor devuelve o si tiene errores sintácticos, semánticos, etc
